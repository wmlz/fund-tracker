# LOF/ETF 实时溢价监控

实时监控场内基金（LOF/ETF）的**真实溢价率**，通过跟踪标的（如白银期货）的实时行情抹除基金净值更新的一个交易日延迟。

## 原理

场内基金净值每日盘后公布，滞后一个交易日，导致用「最新净值」计算的溢价率失真。本工具用**实时跟踪标的涨跌幅**估算实时净值：

```
实时估算净值 = 最新单位净值 × (1 + 跟踪标的本日涨跌幅)
实时溢价率   = (场内价格 ÷ 实时估算净值) − 1
```

例如国投白银LOF(161226)：场内价 1.902（+3.76%），沪银主力今日 +5.17%，最新净值 1.7654（昨日）。用旧算法溢价率约 +7.7%，抹除延迟后实际约 +2.4%，差异巨大。

原油 LOF 因净值滞后天数不固定（QDII 常见滞后 1-2 个交易日），改用**锚定累计涨跌**算法：以最新净值日为锚，用标的日K收盘价与实时价计算累计涨跌，自动覆盖任意滞后天数。

```
锚定价   = 最新净值日 D0 对应的标的日K收盘价
累计涨跌 = 实时价 ÷ 锚定价 − 1        （多标的按权重加权）
实时估算净值 = 最新净值 × (1 + 加权累计涨跌)
```

## 功能

- **实时仪表盘**：场内价、跟踪标的、估算净值、实时溢价率（正溢价红/负溢价绿）
- **盘中走势图**：会话内场内价 / 估算净值 / 溢价率三条线（5 秒轮询）
- **历史溢价率曲线**：近 120 日「场内收盘价 ÷ 当日净值 − 1」
- **阈值预警**：可设上下阈值，超限高亮 + 浏览器通知
- **多基金支持**：下拉切换 + URL 参数 `?code=161226` 直达，配置驱动，加基金只需改一行

## 部署

### 方式一：Vercel（推荐）

自带 serverless 代理，可获取国内商品期货主力（上海期货交易所）实时行情，估算最准确。

```bash
npm i -g vercel
vercel           # 登录并按提示部署
vercel --prod    # 部署到生产
```

部署后地址形如 `https://xxx.vercel.app`，打开即可，`/api/quote` 与 `/api/nav` 自动生效。

### 方式二：GitHub Pages（纯静态）

无后端代理，自动降级：跟踪标的改用腾讯国际白银（COMEX）近似，净值改用天天基金 `pingzhongdata`（可能滞后/日期偏移一天）。适合快速体验或做静态托管。

把本仓库推送到 GitHub，Settings → Pages → 选择分支即可。前端代码无需改动。

## 添加新基金

编辑 `funds.js`，按 `tracker.type` 指定跟踪标的数据源：

```js
window.FUNDS = {
  '161226': {                       // 基金代码
    code: '161226',
    name: '国投瑞银白银LOF',
    market: 'sz',                   // 场内市场: sh / sz
    tracker: {
      type: 'futures',              // 标的类型: futures | composite
      symbol: 'nf_AG0',             // 新浪国内期货代码（经代理）
      fallback: { source: 'tencent', symbol: 'hf_SI' }  // 代理不可用时的降级源
    }
  }
};
```

- **国内商品期货基金**：`type: 'futures'`，新浪期货代码如 `nf_AU0`(黄金)、`nf_CU0`(铜)，代理白名单接受 `nf_` 前缀
- **国际原油等组合型**：`type: 'composite'`，多标的按权重加权，实时价走腾讯直连（`hf_CL`=WTI、`hf_OIL`=布伦特），日K锚定价走 `/api/kline` 代理：

```js
'501018': {
  code: '501018', name: '南方原油LOF', market: 'sh',
  tracker: { type: 'composite', symbols: [
    { source: 'tencent', symbol: 'hf_CL', weight: 0.6, kline: 'CL' },
    { source: 'tencent', symbol: 'hf_OIL', weight: 0.4, kline: 'OIL' }
  ]}
}
```

`kline` 字段对应新浪 GlobalFutures 日K代码（`CL`/`OIL`），白名单在 `api/kline.js` 中，可扩展其他外盘品种。

- **指数 ETF/LOF**：`type: 'index'`，在 `datasource.js` 的 `getTrackerQuote` 中按腾讯指数接口扩展一个分支即可（场内价/净值/K线/历史曲线全部通用）

## 数据源

| 数据 | 来源 | 说明 |
|------|------|------|
| 场内实时价/分时/日K | 腾讯行情 | 浏览器直连（CORS 开放） |
| 历史净值 / 最新净值 | 东方财富 f10（经 `/api/nav` 代理） | 准确到最新净值 |
| 国内商品期货主力 | 新浪期货（经 `/api/quote` 代理） | 白银等，最准确 |
| 外盘原油实时价 | 腾讯外盘 `hf_CL` / `hf_OIL` | 浏览器直连 |
| 外盘原油日K（锚定价） | 新浪 GlobalFutures（经 `/api/kline` 代理） | 用于原油累计涨跌 |
| 降级：国际白银 | 腾讯外盘 `hf_SI` | 仅当代理不可用时 |

## 估算精度说明

- **白银 LOF（国内期货，人民币计价）**：估算误差很小（<0.1% 量级），净值与沪银主力严格联动。
- **原油 LOF（QDII，美元计价）**：净值受人民币汇率、净值滞后补涨、跟踪误差影响，回测显示估算误差约 ±1-2%。界面会标注「基准净值日期 / 滞后交易日」，供自行判断口径。
